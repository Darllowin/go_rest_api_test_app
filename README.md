Простое REST API приложение на Go для тестирования и обучения.

## 📦 Описание

Это небольшой проект на Go, реализующий REST API с простыми CRUD-эндпоинтами (работа с задачами TODO).  
Цель — практиковаться в разработке REST-сервисов и написании тестов.
